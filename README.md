# 心迹

一个用来记录「状态强弱与占卜灵光」的私人记录工作台。
纯网页应用，不需要后端：所有数据只保存在你自己的浏览器里，不会上传到任何服务器。

## 这个仓库里有什么

| 位置 | 用途 |
| --- | --- |
| 仓库根目录（本文件所在处） | **给你自己部署和修改的源码**，标准 Vite 项目，直接构建即可 |
| `心迹-源码/` | 原作者自动打包安卓安装包与发布网页的工程，含成品安装包、签名与自动脚本；私人部署可忽略 |
| `.github/workflows/` | 原作者的自动构建流程，与私人部署无关 |

只想自己部署网页的话，**只使用根目录的文件**即可，Netlify / Vercel 导入仓库后填好构建命令就能直接跑。

## 能做什么

- 按主体记录状态、事件与备注，支持配图
- 用图表回看一段时间里的趋势与脉络
- 导入 / 导出 JSON、CSV，方便备份和迁移
- 自定义背景图、卡片透明度等外观

## 开源许可

支持二改二传和私人部署，严禁倒卖。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
pnpm install
pnpm run dev
```

没有 pnpm 也可以用 `npm install` / `npm run dev`。
浏览器打开终端里显示的地址（通常是 http://localhost:5173）。

## 部署到你自己的空间

```bash
pnpm run build
```

构建结果在 `dist/` 目录，把整个目录上传到任意静态网站托管即可：
Netlify、Vercel、Cloudflare Pages、GitHub Pages，或你自己的服务器。

**部署在网站根目录（最常见）** — 不用改任何配置，直接上传 `dist/`。
在 Netlify / Vercel 导入仓库时填写：

| 项目 | 内容 |
| --- | --- |
| 构建命令 | `pnpm run build`（或 `npm run build`） |
| 发布目录 | `dist` |

**部署在子目录**（例如 GitHub Pages 的 `/你的仓库名/`）— 构建时指定子路径，否则会一直停在开屏画面：

```bash
VITE_BASE_PATH=/你的仓库名/ pnpm run build
```

Windows 下可以先复制 `.env.example` 为 `.env`，在里面写 `VITE_BASE_PATH=/你的仓库名/`，再执行构建。

## 可配置项

复制 `.env.example` 为 `.env` 即可修改（`.env` 不会被提交）。不配置也能直接运行。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `VITE_BASE_PATH` | `/` | 部署子路径 |
| `VITE_APP_VERSION` | `1.2.2` | 设置里显示的版本文字，可改成你自己的 |
| `VITE_BUILD_CODE` | `1` | 版本序号，仅自建安装包更新时用 |
| `VITE_VERSION_URL` | 空 | 自建安装包更新源；留空则关闭应用内更新检查，不连接任何外部地址 |
| `SINGLE_FILE` | 未设置 | 设为 `1` 可构建成单个 HTML 文件，方便离线保存或转发 |

## 数据与隐私

- 数据保存在浏览器本地，换浏览器、清理缓存或换设备都会丢失，请定期用「设置 → 数据 → 导出」备份
- 导入时选择「合并」会把同名主体合并，请仔细核对
- 网页不会向第三方发送数据；默认也不会检查更新、不会连接外部地址

## 自行修改

| 想改什么 | 看哪里 |
| --- | --- |
| 文案、页面内容 | `src/pages/`、`src/features/` |
| 配色与样式 | `src/App.css`、`src/index.css` |
| 应用名称、开屏与图标 | `index.html`、`public/favicon.svg` |
| 存储与合并逻辑 | `src/lib/storage.ts` |

技术栈：React 19 + TypeScript + Vite 7 + Tailwind CSS 4，没有后端依赖。

## 关于安卓安装包

根目录这份源码只包含网页版，不含成品安装包、签名文件和自动打包流程。
如果你需要自己的安卓安装包，可以用 Capacitor 把 `dist/` 打包成 Android 工程，
再通过 `VITE_VERSION_URL` 指向你自己的版本清单来启用应用内更新。
